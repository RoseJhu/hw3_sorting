**一、開發說明**
：本專案實作之排序比較系統，核心演算法結合了多執行緒平行運算與同步動畫邏輯。針對演算法實作採用「手寫邏輯」排除系統內建函式，導入分治與相鄰交換演算法架構。繪圖更新採用Canvas動態繪製技術，確保三個執行緒獨立佈局且動態呈現向外擴散且視覺上互不重疊。

**二、功能特色**
*   **介面設計**：參考「Lo-Fi 復古溫暖調色盤」配置視覺配色，以深棕黑、芥末金與青瓷綠等高對比色系，打造具備 90 年代類比感的視覺氛圍。
*   **效能監測**：提供高精度「Time Perf Counter」計時功能，自動計算至小數點後四位，並透過數值比較判定系統最快演算法贏家。
*   **彈性控制**：提供使用者自訂「重置 Reset」功能，一鍵重構全新隨機不重複數值陣列，具備執行緒鎖定防呆機制預防重複點擊。
*   **視覺動態**：支援 Canvas 陣列動畫與遞迴分治擴展，動態呈現陣列元素交換與各個擊破過程，提升演算法教學之理解程度。
